Reglas básicas compactas

Mesa, carritos de verdad y pista de gis. De dos a diez. Las reglas las cuidan los que juegan. Si hay duda, se mira el carrito.

Salida

El primero de la lista sale adelante y tira primero mientras siga adelante. Cuando ya tiraron todos, tira primero el que va adelante en la pista, luego el segundo y el resto. Si alguien rebasa, no se grita. Ya se sabe que ese abre la vuelta de turnos que sigue. No se mete en el turno que ya iba.

Tiro y línea

El carrito solo camina con un capirotazo del índice. No se empuja ni se arrastra. Cada turno tiene tres tiros. No hace falta usarlos todos: los que no tires no se guardan. Para acomodarlo, gira sobre su eje con una llanta en la mesa. Si lo levantas, se anula el turno.

Tocar la orilla no saca al carrito. Cada tiro que se queda lo deja ahí, y de ahí sale el siguiente: el primero se queda, tiras el segundo; el segundo se queda, tiras el tercero. Si el tercero se sale y ya no toca la línea, el carrito se queda donde hiciste ese tercer tiro. No regresa al inicio del turno.

Zonas marcadas en esa carrera

Solo valen las que estén dibujadas.

  • Exacto. Se detiene en la casilla, se queda y, si le quedan tiros, sigue.
  • Tiro largo. Si el turno acaba en la flecha, el siguiente trae cuatro tiros.
  • Trampa. Se cruza en uno, dos o tres tiros. Si se queda adentro, regresa al inicio de esa sección. No es un foso.
  • Foso. No se puede caer. Si caes, pierdes el turno que sigue.
  • Lava o hielo. El turno que sigue se tira con la mano con la que no escribes.
  • Lluvia. Mientras el carrito esté en ese tramo, el turno solo tiene un tiro.
  • Tráfico. Si quedan pegados, un tiro solo sirve para separarlos. El rival no se mueve.
  • Choque. Si sacas al rival del gis, pierde el primer tiro de su siguiente turno.
  • Rebufo. Justo atrás, a menos de dos centímetros y sin tocar, el siguiente turno gana un tiro.

Si se pelean por la línea o la meta, se mira el carrito. Lo que se ve, vale.
